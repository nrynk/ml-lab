================================================================================
Experiment 8: K-Nearest Neighbors (KNN) for Image Classification using Fashion MNIST Dataset
================================================================================

AIM:
Implement the K-Nearest Neighbors (KNN) algorithm for image classification using the Fashion MNIST dataset. Experiment with different values of K and analyze their impact on model performance.

ALGORITHM / PROCEDURE:
Step 1: Load the Fashion MNIST dataset (from keras.datasets or torchvision / openml / fallback).
Step 2: Normalize pixel values by dividing by 255.0.
Step 3: Flatten 28x28 2D images into 784-dimensional 1D vectors.
Step 4: Select a training subset (e.g., 6,000 samples) and testing subset (e.g., 1,000 samples) for computational efficiency.
Step 5: For K in [1, 3, 5, 7, 9]:
   - Instantiate KNeighborsClassifier(n_neighbors=K).
   - Fit model on training set.
   - Predict test labels.
   - Compute Accuracy, Precision (weighted), Recall (weighted), and F1-score (weighted).
Step 6: Display results summary table and plot Accuracy vs K curve. Save to knn_plot.png.
