================================================================================
Experiment 3: Ridge and Lasso Regression on the Diabetes Dataset with Hyperparameter Tuning
================================================================================

AIM:
To implement Ridge Regression and Lasso Regression on the Diabetes dataset, tune their hyperparameters using Cross-Validation, and compare their performance with Standard Linear Regression.

ALGORITHM / PROCEDURE:
Step 1: Load Diabetes dataset from sklearn.datasets.load_diabetes.
Step 2: Split data into training (80%) and testing (20%) sets.
Step 3: Standardize features using StandardScaler to ensure uniform regularization penalties.
Step 4: Train Standard Linear Regression baseline. Predict test set and calculate MSE and R² score.
Step 5: Implement Ridge Regression with hyperparameter tuning:
   - Use RidgeCV over log-spaced alpha values [1e-3 to 1e3].
   - Determine optimal alpha, predict test set, compute MSE and R² score.
Step 6: Implement Lasso Regression with hyperparameter tuning:
   - Use LassoCV over log-spaced alpha values [1e-3 to 1e3].
   - Determine optimal alpha, predict test set, compute MSE and R² score.
Step 7: Compare all three models in a summary table and analyze feature sparsity from Lasso.
